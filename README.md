# Cybrexa_04_CyberShield

> **Project 4 of 4 — CAPSTONE** | Cybrexa Cybersecurity Portfolio Series

A real-time cybersecurity news and threat intelligence dashboard — the capstone project combining all skills from Projects 1-3.

## 5 Modules
1. **News Aggregator** — Searchable, filterable cyber security news feed
2. **Threat Analytics** — Doughnut + line charts visualizing threat categories and trends (Chart.js)
3. **Live Monitor** — Auto-refreshing security event feed, updates every 3 seconds
4. **IP & Source Intel** — WHOIS-style IP lookup with geo simulation
5. **Knowledge Hub** — Searchable cybersecurity glossary (30+ terms)

## Tech Stack
`HTML5` · `CSS3` · `Vanilla JavaScript` · `Chart.js`
